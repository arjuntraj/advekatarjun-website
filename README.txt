advekatarjun.com – website files

Upload EVERYTHING in this folder (index.html and the "art" folder) to the
main/public folder of your web hosting (often called "public_html" or "www").
Keep the "art" folder next to index.html.

To add a new drawing to the Art wall: put the picture in the "art" folder, then in
index.html copy one <li>...</li> line inside <ul class="wall"> and change the file
name, title and description.

When the book is live on Amazon: open index.html, search for "Coming soon on Amazon",
and follow the note just above it.
